**Run:** 2026-06-14 · TEST run · output language: English (production default is Vietnamese)

## Research question
In adults **without diabetes**, do GLP-1 receptor agonists (semaglutide, tirzepatide) reduce major
adverse cardiovascular events when used for **primary** prevention (no established cardiovascular disease)?

| PICO | |
|---|---|
| **P** | Adults without diabetes; overweight/obese; **without** established CVD (primary-prevention population) |
| **I** | GLP-1 RA (semaglutide 2.4 mg; tirzepatide) ± GIP |
| **C** | Placebo / standard care |
| **O** | Primary: 3-point MACE (CV death, nonfatal MI, nonfatal stroke). Secondary: all-cause mortality, weight, safety/discontinuation |

## Inclusion / exclusion
- Include: RCTs, meta-analyses/SRs, major-body guidance, trial-registry entries; non-diabetic adults; 2020–present; English.
- Exclude: pure type-2-diabetes populations (unless a non-DM subgroup is reported); animal/in-vitro.
- ⚠️ Scope tension: most evidence enrolls **established-CVD (secondary-prevention)** patients — flag, don't silently include as primary.

## Sources & search strings
- PubMed: `semaglutide + cardiovascular outcomes + obesity + without diabetes`; `GLP-1 RA[tiab] AND primary prevention[tiab] AND cardiovascular[tiab] AND non-diabetic`.
- ClinicalTrials.gov: intervention semaglutide/tirzepatide × cardiovascular/obesity; phase 3–4; ongoing.
- Consensus: GLP-1 RA primary CV prevention without diabetes.
- bioRxiv/medRxiv: recent preprints (keyword search unsupported — category/date scan only).

## Curiosity budget (gap-directed)
1. **Contradiction gap:** does the "primary prevention" label hold, given SELECT enrolled established CVD?
2. **Population gap:** Vietnamese / Asian non-diabetic data — `Vietnam[Affiliation]` (pending).
3. **Evidence gap:** is there any RCT with a *true* primary-prevention (no-CVD) non-diabetic population, or only extrapolation?

## Pre-registered outcomes: MACE, all-cause mortality, CV death, stroke (separately), discontinuation.
