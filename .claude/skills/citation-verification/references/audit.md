# Pre-delivery audit
Load only at verification. An audit records evidence, not confidence in the process.

## Mechanical preflight and final checks
Before semantic QA run quote and claim-link checks (`docs/claim-links.md`) to fix mechanical defects
cheaply. After lead revisions run them on the EXACT final Markdown and run `citation_audit.py`
with coverage floor 0.4. Any required failure blocks delivery. Record actual exit codes/report paths.
P1 traceability and P8/link checks do not prove semantic support. No claim-level QA is replaced by sampling.

## Process and scope
- Scope: quote explicit request/answers for purpose, depth, audience, date window and topic; Vietnamese
  default is recorded. No repeat questions for explicit fields. No invented missing scope.
- Retrieval: planned independent sources, gap probes, source-folder reconciliation, reproducible ledger,
  actual PRISMA counts, retraction checks, full-text gaps and deferred-unread studies recorded?
- Research Map: actual presented map and approved source list match recorded hash; quote real user
  approval received after presentation. A PDF-supply choice/unrelated answer does not clear the gate.
- Appraisal: design-appropriate RoB, outcome-level GRADE reasons, contradictions and Assumption Register?
  Conditional decision reason in state; material scope changes reopen map; ordinary uncertainty does
  not require an extra approval. If decision was pending, actual approval receipt is required.
- Synthesis: thematic integration, explicit consensus/controversy, all planned subgroups treated where
  data exist, counter-evidence considered, calibration matches BOTH certainty and study design?
- Coach: not_needed with reason in state, or report with at most one improvement pass applied. No
  mandatory coach based solely on effort, and no separate skip essay.
- Lessons: no_new_lesson or an evidence-based proposal; cross-study persistence only if approved.
- Deliverable: final Markdown and compact QA/audits; generated manifest indexes current artifacts,
  confidence/outcomes and open assumptions. Generate manifest AFTER final checks, not before QA.

## Content checks and report
Check each substantive claim against original source context, not just whether the citation resolves.
Include uncited prose; compare evidence certainty and design; verify no hidden full-text/coverage claim.
Use claim IDs to avoid duplicating every passing paragraph. Report checked IDs + hashes, defects
with precise correction, rubric per-criterion rationale/band, gate receipts and residual limitations.
Audit all six constitutional laws. Never deliver fabricated citation, unapproved map, unresolved
substantive mismatch or failed/missing required check. Nonblocking limitations remain transparent.
Recommend human review of pivotal claims; explicitly mark it pending unless actual review took place.
